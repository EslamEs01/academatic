# Targeted Visual Grounding

Before any visual, workflow, form, privacy, or role-surface change: read the
active Spec and contracts, inspect the current source and flow, open the exact
relevant legacy and current screenshots **as images**, and read matching
planning/deep-planning/raw HTML/JSON/text/source records. Map each proposed
capability to direct evidence and compare it with the current product.

Raw records and pixels beat summaries. A filename, OCR, or inferred layout is
not visual evidence. Preserve authored improvements; never guess missing states,
fields, ownership, permissions, or layouts. Record contradictions and stop for
direction rather than smoothing them over. Check AR/EN, RTL/LTR, responsive,
keyboard/focus, loading/empty/error states, and required complete-form fields
when evidence calls for them.
