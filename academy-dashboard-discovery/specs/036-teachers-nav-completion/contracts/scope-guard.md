## Stop conditions (halt + report)
- Public HTML count ≠ 115 after build.
- A standalone add-teacher / sessions-kpi / monthly page is required.
- sessionsKpi/monthlyPerf require a computed percentage/score/rank/chart.
- Any salary/rate/fine/payout/currency figure is required on a teacher surface.
- Any final action fakes success; any row/status mutates.
- backend/API/network/dependency introduced; `type=file`/`type=password` appears.
- `package.json`/`enhance.js`/`build-html.mjs`/`i18n.js` must change.
- A role-law / no-fake / teacher-pay / no-computed-score protected assert would need weakening.
- `teachers.html`/`teacher.html` body cannot stay byte-identical.
