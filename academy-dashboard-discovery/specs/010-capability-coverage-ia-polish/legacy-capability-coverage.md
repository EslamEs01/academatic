# Legacy Capability Coverage Matrix (Spec 010)

**Status**: Draft for product-owner sign-off · Binding artifact per `contracts/legacy-capability-coverage-contract.md` (FR-001–FR-005, SC-001/SC-002, research D9).

This matrix is documentation only — it never ships as an app page. It exists so that every capability the legacy academy system offered has exactly one auditable answer: implemented, renamed, moved, merged, planned, backend-required, future-role, intentionally excluded, or a newly-logged gap. Nothing here copies legacy visuals, classes, palette, wording, or numeric status codes — only the *capability* (what it let an admin do) is carried forward as a plain-English description.
