# Spec 044 Verification Quickstart

Run from `academy-dashboard-discovery/app` unless noted.

## Preconditions

1. Branch is `044-modal-drawer-long-form-interaction-system`.
2. No unrelated working-tree changes or mutation copies exist.
3. Authored source is the only application edit authority; `public/` is regenerated by the build.

## Focused development loop

```bash
npm run build
node tests/interaction/run.cjs
npm run test:smoke
```

The interaction guard must fail loudly for absent/duplicate targets and selectors. Never wrap required interaction assertions in optional catches.

## Full acceptance loop

```bash
npm run build
node tests/interaction/run.cjs
npm run test:smoke
npm run test:a11y
npm run screenshots
git diff --check
```

Expected acceptance:

- 115 generated HTML pages unless an inventory-proven page change is documented;
- exact inventory and AR/EN parity;
- all smoke and interaction scenarios pass;
- accessibility critical=0 and serious=0;
- screenshot console errors=0;
- protected Spec-043 guards remain green;
- every registered mutation produces its exact intended RED then primary-tree GREEN;
- mutation residue=0;
- unrelated page-body drift=0.

## Manual review

Open representative captures at original detail for confirmation, form modal, detail drawer, long-form drawer, unsaved confirmation, validation/backend-required state, mobile sidebar, dropdown, wizard, AR/EN, both themes, desktop, and 390px. Confirm no clipping, focus loss, stacked overlay, off-screen action, false save, or privacy regression.

## Mutation protocol

For each mutation: create a fresh isolated copy, apply exactly one mutation, run only the mapped guard, prove the intended assertion caused RED, remove the copy, and rerun the primary guard GREEN. Never mutate the primary tree and never reuse a dirty isolated copy.
