# Contract: Design Freeze (Spec 016)

**Status**: Binding on Specs 017–027 · Binds `role-dashboard-design-freeze.md`.

1. Every UI decision in 017–027 resolves to a frozen-as-exists pattern (shipped reference) or a frozen-new pattern (defined in the freeze, built once in its owning spec).
2. The forbidden-visual-patterns register is closed law; a frame exhibiting any entry fails screenshot acceptance.
3. Role accents locked (student sky · family violet/primary · teacher teal · admin violet); no new colors, fonts, icon systems, or nav paradigms.
4. Change control: deviations require an explicit amendment section in the deviating spec's plan (Spec-015 A1/A2 precedent). Silent drift = 027-blocking finding.
5. No spec 017–027 may contain an open design question — if one appears, it is resolved by amendment to the freeze, not by ad-hoc invention.

**Acceptance**: each future spec's plan cites the freeze; REVIEW.md verdicts reference the forbidden register; zero unfrozen patterns ship.
