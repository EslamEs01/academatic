# Teacher Domain Visual System Contract

1. One coherent Teacher-domain hierarchy spans all eleven pages while portal and admin shells remain distinct.
2. Existing Academatic tokens, typography, spacing, radii, colors, icons, cards, tabs, filters, status chips, and shells remain authoritative.
3. Page composition prioritizes: identity/purpose → actionable work → primary records → supporting context → truthful terminal limits.
4. Repeated records use compact readable metadata, categorical labels, and calm actions; they do not become identical card walls or dense unstructured waterfalls.
5. No decorative chart, gradient, glass surface, shadow, oversized hero, or filler module may be introduced without evidence and usability value.
6. Additive shared Teacher patterns are preferred over eleven page-local styles. Global selector changes require a consumer list and non-Teacher regression proof.
7. Every visible module maps to EG-045-01–11. Reference defects are not copied; later accepted Academatic improvements are preserved.
