# Spec 044 Interaction Integration Contract

Teacher-domain content may compose existing shared modals, drawers, confirmations, dedicated Add/Categories pages, menus, and mobile sidebar. Spec 045 does not fork their controllers.

For every affected interaction, verification proves:

- required opener and exact target;
- correct family and accessible dialog semantics;
- deterministic close, safe/dirty Escape and overlay behavior;
- purposeful initial focus, containment, background isolation, and exact opener restoration;
- body lock and scroll restoration;
- stable header/content/footer/action and full-screen 390px behavior;
- validation/value preservation and truthful backend-required state;
- one overlay/trap/lock/listener; no nested modal-grade surface;
- AR/EN and theme parity;
- required selector failure is loud.

A shared defect is recorded as a bounded Spec-044 regression correction and tested across all affected consumers. A Teacher composition defect remains owned by 045.
