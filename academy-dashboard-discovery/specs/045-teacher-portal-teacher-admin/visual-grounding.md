## Visual comparison findings

- **Reference strength retained:** clear teacher purpose, daily schedule priority, student-to-history/report relationships, library discovery controls, admin directory scopes, deep teacher-detail navigation, and explicit performance period/filter concepts.
- **Current strength retained:** Academatic tokens and shell, mobile agenda transformation, descriptive rather than computed performance, safe role separation, pay-free fixtures, honest backend gates, shared Spec-044 dialogs/drawers, AR/EN source parity, and dark-theme components.
- **Cross-domain defect:** current teacher pages share components but not enough domain rhythm; internal portal pages are sparse while admin detail is dense. Spec 045 must establish a bounded Teacher visual composition without changing global navigation or unrelated pages.
- **390px defects/risks:** teacher performance cards become very tall; admin detail action rows waterfall; portal navigation needs truthful states; every modified layout requires exact-width overflow/clipping review.
- **Evidence gaps that are verification work, not permission to invent:** the legacy platform has mostly English/light desktop captures and no reliable dark/mobile set. Current generated AR/EN sources establish locale parity, while final Spec-045 capture must create the mandated AR/EN, light/dark, desktop/390 matrix.
