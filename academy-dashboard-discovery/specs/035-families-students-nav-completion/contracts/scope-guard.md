## Forbidden to touch
```
package.json                      (0-diff — no new dependency)
any backend/API/auth/database file (none exist; introduce none)
finance/payroll pages · teacher pages · settings pages   (no body edit)
portal pages / control pages      (except shared-sidebar regen)
enhance.js                        (expected 0-diff; no new hook/storage key)
any protected smoke regex         (byte-verbatim)
other specs                       (except append-only status note if strictly needed)
```

## Stop conditions (halt + report)
- Public HTML count ≠ 115 after build.
- schedule-search needs a real availability engine / backend / external request to function.
- studentResult/studentEvaluation are pushed to require a computed score/rank/rubric total or an aggregate board.
- familyCategories cannot become a real anchor to an existing surface.
- Any final action fakes success; any row/status/result mutates.
- backend/API/network/dependency introduced; `type=file`/`type=password` appears.
- `package.json` changes; a role-law/no-fake protected assert would need weakening.
- The hash-route deep-links cannot pass link-integrity without relaxing a protected check.
