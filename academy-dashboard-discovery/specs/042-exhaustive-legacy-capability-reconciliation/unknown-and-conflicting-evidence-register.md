# Spec 042 — Unknown & Conflicting Evidence Register

**Purpose**: the single canonical list of (a) every `UNKNOWN_EVIDENCE` disposition row across the
15 cluster audits + `privacy-and-sensitive-data-findings.md` (U-01…U-03), and (b) every entry of
every "Evidence conflicts" section (C07 §5 · C08 §5 · C09 §4 · C10 §6 · C12 §5 · C13 §5 · C15 §5,
plus the de-facto conflict sections C11 §0 and C14 §1). Rows are deduplicated across clusters —
each row lists the audit rows it consolidates.

**Rules applied throughout**: raw records (`output/roles/<role>/pages/<slug>.json`, `text/`,
`html/raw/`) beat planning summaries and prior-spec claims; shipped code beats stale spec
artifacts; pixels + raw forms beat module tags. **Nothing marked unknown may ever be invented** —
each row names EXACTLY ONE primary future owning spec (pure backend prerequisites carry a
FUTURE_BACKEND note with the nearest owner). Paths resolve relative to `academy-dashboard-discovery/`.

Note on the C14 error corpus: **12 of the 19 C14-cluster legacy pages are error captures** (seven
HTTP 500s md5-identical in pairs, one 504, four byte-identical branded 404s of `main/index.html`).
The four 404 captures attach to no capability and are accounted for here as part of UK-33's
evidence-index record; the 500/504 capabilities get their own rows (UK-02…UK-07).
